Welcome

This is the company's internal home page. It is only reachable from inside the office network. If you can read this page by typing intranet.company.local, your computer received its settings automatically from the DHCP server and the DNS server found this web server for you. No IP address needed.

Announcements

Plug in and go

Use names, not numbers

IT help: my computer is not online

  1. Check that the network cable is firmly plugged in and the link light is on.
  2. Make sure the network adapter is set to obtain an IP address automatically.
  3. Open the command prompt and run ipconfig /all. A good address starts with 192.168.10.
  4. If the address starts with 169.254, the computer did not reach the DHCP server. Reconnect the cable and try again.
  5. Run ping 192.168.10.1. Replies mean you can reach the router.
  6. Run nslookup intranet.company.local. If it fails but the ping works, tell IT that DNS is not answering.

Policies

Passwords

Use a long, unique password and never share it. IT will never ask for your password.

Network use

Do not assign yourself a fixed IP address. Fixed addresses are reserved for the router and servers, and a duplicate address can take another computer offline.

Company data

Keep work files on company storage, not on personal devices.

FAQ

Why does my computer get a different address from my colleague's?

The DHCP server gives every computer the next free address from its pool, so each one is different. That is how duplicate addresses are avoided.

Will my address change?

It can. The address is leased for a period of time and renewed automatically. The intranet name stays the same, so you never need to track it.

Why can I open the intranet by name but not by a website on the internet?

This office network is isolated. The intranet name is known only to the company DNS server.
